# Lensprout landing page

A static marketing site (landing page and blog) for the Lensprout Chrome extension. It is a separate project from `../extension/` and imports nothing from it.

Stack: Astro 7 (static output, React islands), React 19, TypeScript 7, Tailwind CSS v4, Hugeicons, Fredoka and Nunito via @fontsource (OFL). Node 24 or newer.

## Commands

```bash
npm install
npm run dev        # http://localhost:5180
npm run build      # typecheck, static site in dist/, then the web editor in dist/editor/
npm run preview    # serve dist/ on http://localhost:5181
npm run check      # needs a build first: screenshots + axe + overflow checks
```

`npm run check -- <dir>` writes full-page screenshots (light/dark × 1440 px/360 px), axe results, horizontal-overflow measurements and theme-toggle/FAQ interaction results to `<dir>` (default `screenshots/`). It uses the Playwright Chromium build; run `npx playwright install chromium` if it is missing.

`npm run build` also builds the web editor from `../extension` (`npm run build:web` there, installing its dependencies if needed) and copies it to `dist/editor/`, served at `/editor/`. `npm run dev` does not serve it; run `npm run dev:web` in `../extension` (http://localhost:5190/editor/) to work on it.

## Where things are

- `src/pages/`: the home page (`index.astro`), the blog (`blog/`), the 404 page, RSS, robots and `/license.txt`.
- `src/components/sections/`: home page sections (hero, scroll story, features, showcase, how it works, privacy, pricing, FAQ, get it).
- `src/components/demos/`: the small animated feature demos used by the features section.
- `src/content.ts` and `src/content/blog/`: page copy and the blog posts. Copy must only describe features the extension actually ships (see `../docs/PRODUCT_SPEC.md`).
- `src/site.ts`: the site URL and the store and GitHub links (placeholders until published).
- `src/styles.css`: the Lensprout Coral Playground tokens (the same AA-adjusted values as the extension) for light and dark.
- `src/brand/`: mascot geometry and logo, copied from `../extension/src/components/brand/`. Keep them in sync by hand.
- `src/assets/screens/` and `public/media/`: product screenshots and the two demo clips, recorded with the extension.
- `public/favicon.svg`: generated by `npm run favicon` from the mascot geometry.

## Placeholders

- "Add to Chrome" links to the on-page `#get` section, which says the Chrome Web Store listing is coming soon. Set `CHROME_STORE_URL` once a listing exists.

## Deploy

The site is live at https://lensprout.myudak.com (Vercel project `myudaks-projects/lensprout`, connected to the GitHub repository `myudak/lensprout`).

- **Every push to `main` deploys to production.** Other branches and pull requests get preview deployments.
- Vercel builds from the repository with Root Directory `landing` (Astro preset), so `scripts/build-editor.mjs` can reach `../extension` to build the web editor. A CLI deploy from `landing/` alone uploads only that folder and fails at the editor step; push instead.
- `src/site.ts` holds `SITE_URL`; change it if the domain changes.
- `/privacy/` is the Chrome Web Store privacy policy URL; update it whenever the extension's data handling or permissions change.
