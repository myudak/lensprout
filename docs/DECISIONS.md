## Retain these distinctions

The original Cursorful capture uses desktop capture/WebCodecs and a website editor. Its bundled renderer exposes useful grouping/spring behavior, but complete editor UI/default invocation/backend are absent. Our React local editor, source capture and planner are new choices. Original cloud/native endpoints and protocols are not dependencies.

Pinned dependency versions are in `extension/package.json` and `package-lock.json`. Vitest 4.1.11 was selected for Node 25 compatibility and its fixed mocker version; a trial of 5.0.3 had an unsupported Node engine warning and a trial of 4.1.2 had audit findings. Current dependency audit is recorded in verification.

Audit item A12 (cursor is baked into captures): since v0.5.0 an overlay cursor and highlight are offered on top of the captured cursor (D48); smoothing, sway and removal of the real cursor remain impossible and the UI says so.

Revisit a decision when measured evidence, user scope or a versioned contract requires it. Log changes and migration needs. Routine implementation choices within the authorized scope do not require renewed permission.
